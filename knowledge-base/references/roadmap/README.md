# knowledge-base/references/roadmap/

Roadmap material lives here, on its own, because it is the **part of `references/` that changes most between cycles** — so it gets refreshed every run while the slower-moving strategy and vision material stays put.

What belongs here:

- Roadmap slides and decks (initiative timelines, quarter-by-quarter feature plans).
- Roadmap screenshots and exports.
- Anything that states **what is GA today vs. what is on the roadmap and when** — the agent leans on this to answer capability questions accurately and to phrase roadmap dates (named capability + target quarter).

Refresh this **first**, every cycle (see the per-cycle checklist in [`../../../SETUP-INSTRUCTIONS.md`](../../../SETUP-INSTRUCTIONS.md)). Roadmap facts age fastest; a stale roadmap here is how a shipped-or-not answer goes wrong.

Nothing in this folder is committed to git except this guide — see [`../../../.gitignore`](../../../.gitignore).
